# web y generar

## Web
1. `search_web.py --q "…" --out data/web.json` (o `--offline-demo` en pruebas sin red).
2. Usa solo `accepted`. Revisa `rejected` (p. ej. Wikipedia irrelevante).
3. Etiqueta siempre como fuente externa.

## Generar
1. Elige perfil DM o ML.
2. Parte de plantillas en `templates/experiments/` y `templates/exam/`.
3. Simulacro: no incrustes soluciones; apunta a `*_SOLUCIONES.md`.
4. Ancla el contenido al retrieve del índice.
