# aprender — ciclo del método

**Orden obligatorio:** teoría → práctica → simulacro.

1. Perfil `dm` o `ml`.
2. Indexar si hace falta.
3. `query_index.py` del tema; mostrar citas.
4. Generar:
   ```bash
   python3 …/generate_learning.py --index data/index --tema "…" --perfil dm|ml --outdir examples/generated
   ```
5. Estudiante completa **FASE 1 teoría** (en ML: notebook A1).
6. Luego **FASE 2 práctica/experimento** (en ML: notebook A2).
7. Luego **Producto B** simulacro; soluciones solo al final.
8. No saltar a código sin teoría. No entregar solo índice.
