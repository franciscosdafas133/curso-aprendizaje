# aprender — método del brief

1. Elegir perfil **dm** o **ml**.
2. Indexar materiales.
3. Generar:
   ```bash
   python3 …/generate_learning.py --index data/index --tema "…" --perfil dm|ml --outdir examples/generated
   ```
4. **Producto A** (aprender): teoría → experimento **conectados** en el cuaderno conceptual-experimental.
5. **Producto B** (evaluar):
   - DM → solo simulacro **práctico**
   - ML → simulacro **teórico** + simulacro **práctico** (archivos distintos)
6. Soluciones solo al final.
7. No inventar “examen oficial”. No quedarse solo en indexar.
